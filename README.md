 О проекте

Car Rental — это веб-приложение, созданное для организации процесса краткосрочной и долгосрочной аренды автомобилей. Платформа объединяет владельцев автомобилей и арендаторов в единой цифровой экосистеме, обеспечивая удобство, прозрачность и безопасность сделок.

Основные возможности


Гость Просмотр каталога автомобилей, фильтрация, информация о тарифах, регистрация 
Арендатор Бронирование авто на даты, онлайн-оплата, история бронирований, отзывы 
Владелец Размещение объявлений, управление бронированиями, подтверждение/отмена 
Администратор Управление пользователями, модерация объявлений, управление автопарком 

 Ключевые функции

- 📱 Поиск и фильтрация — по марке, модели, цене, датам, местоположению
- 📅 Бронирование — выбор дат, автоматическая проверка доступности
- 💳 Онлайн-оплата — интеграция с платёжными системами
- ⭐ Рейтинговая система — отзывы и оценки арендаторов и автомобилей
- 🔔 Уведомления — о статусе бронирования, напоминания
- 🛡️ Модерация — проверка объявлений и пользователей

  Технологический стек

Frontend Vue.js 3, Vue Router, Pinia, Axios, CSS3 
Backend Node.js, Express.js 
Database PostgreSQL 13+ 
Authentication JWT, bcrypt 
Design Figma (прототипы интерфейсов)

Архитектура

Проект построен по модульному принципу с разделением на клиентскую и серверную части:


car-rental/
├── backend/
│   ├── controllers/     # Обработчики запросов
│   ├── models/          # Модели данных (User, Car, Booking, etc.)
│   ├── routes/          # API маршруты
│   ├── middleware/      # Аутентификация, валидация
│   ├── services/        # Бизнес-логика (оплата, уведомления)
│   └── server.js        # Точка входа
├── frontend/
│   ├── src/
│   │   ├── components/  # Vue компоненты (карточки авто, формы)
│   │   ├── views/       # Страницы (каталог, профиль, админка)
│   │   ├── stores/      # Pinia хранилища
│   │   ├── services/    # API сервисы
│   │   └── router/      # Маршрутизация
│   └── public/          # Статика (изображения, иконки)

 База данных

Спроектирована в 3 нормальной форме (3NF), содержит ключевые таблицы:

- `users` — пользователи (арендаторы, владельцы, администраторы)
- `cars` — автомобили (характеристики, цена, локация, владелец)
- `bookings` — бронирования (даты, статус, сумма)
- `reviews` — отзывы и рейтинги
- `payments` — платежи и транзакции
- `notifications` — уведомления пользователей

Установка и запуск

bash
# Клонирование репозитория
git clone https://github.com/Mikhail1708/car-rental-frontend.git
cd car-rental-frontend

# Установка зависимостей бэкенда
cd backend
npm install

# Настройка базы данных
createdb car_rental
cp .env.example .env  # заполните своими данными

# Выполнение миграций
npm run migrate

# Запуск сервера
npm run dev

# Установка зависимостей фронтенда (новый терминал)
cd ../frontend
npm install
npm run dev


Приложение будет доступно:
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:3000`

Безопасность

- JWT-аутентификация (токен с ограниченным временем жизни)
- Хеширование паролей (bcrypt)
- Защита от XSS и SQL-инъекций
- Валидация входных данных на клиенте и сервере
- HTTPS (в production)

 Производительность

- Время отклика API < 2 секунд
- Загрузка страниц < 3 секунд
- Доступность системы > 99%
- Резервное копирование данных
